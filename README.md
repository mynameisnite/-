# -
AI-система для обработки фото: VLM анализирует объекты, сцены и эмоции; LLM генерирует имена файлов и теги. ML-модели проверяют качество, ищут дубликаты и размытие. Извлекает EXIF, геолокацию, время. RAG категоризирует по базе знаний. Распознает лица, группирует по событиям, сортирует по папкам.
